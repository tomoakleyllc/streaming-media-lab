# Lab 01: Basic Live Stream

Goal:
Successfully stream from OBS to YouTube.

Tools:
- OBS Studio
- YouTube Live

Observations:
- Average bitrate: 2656.5 kb/s
- Resolution: 1920 x 1080
- Frame rate: 59.94
- Dropped frames: 0.0%

Issues:
- None

Lessons Learned:
- OBS uses RTMP to send content to YouTube.
- YouTube converts incoming streams into HLS for viewers.
